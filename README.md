## Tools dan Library yang Digunakan
### Beberapa tools dan library yang digunakan selama praktikum antara lain:
- Python : Bahasa pemrograman utama untuk pengolahan dan analisis data
- Google Colab : Lingkungan untuk menjalankan notebook secara online
- Jupyter Notebook : Lingkungan interaktif untuk menjalankan kode dan mendokumentasikan eksperimen
- Pandas : Manipulasi dan pengolahan data berbentuk tabel
- NumPy : Operasi numerik dan manipulasi array
- Matplotlib : Pembuatan visualisasi data
- Seaborn : Visualisasi statistik
- Scikit-learn : Preprocessing, Machine Learning, clustering, PCA, dan evaluasi model
- SciPy : Pengolahan dan analisis statistik
- Requests : Mengakses data dari API
- Imbalanced-learn (imblearn) : Penanganan data tidak seimbang menggunakan teknik resampling
- NLTK : Pengolahan data teks dan kebutuhan NLP
- TensorFlow / Keras : Pengenalan dan implementasi Neural Network
- GitHub : Penyimpanan, version control, dan dokumentasi portofolio

### Cara Menjalankan Notebook
- Menjalankan Secara Lokal
  Pastikan Python dan Jupyter Notebook sudah terpasang pada perangkat.

### Clone repository:
- git clone https://github.com/username/nama-repository.git

### Masuk ke folder repository:
- cd nama-repository

### Install library yang dibutuhkan:
- pip install pandas numpy matplotlib seaborn scikit-learn scipy requests imbalanced-learn nltk tensorflow

### Jalankan Jupyter Notebook:
- jupyter notebook
  Setelah Jupyter Notebook terbuka di browser, pilih file .ipynb yang ingin dijalankan sesuai dengan pertemuan yang tersedia.

Catatan: Beberapa notebook menggunakan dataset atau sumber data tertentu. Pastikan file dataset yang dibutuhkan tersedia pada folder yang sesuai atau sesuaikan path dataset sebelum menjalankan notebook.

### Menjalankan Menggunakan Google Colab
Notebook juga dapat dijalankan melalui Google Colab. Caranya cukup dengan mengunggah file .ipynb ke Google Colab atau membuka notebook dari repository GitHub.

Setelah notebook terbuka, jalankan setiap cell secara berurutan dari bagian paling atas. Jika terdapat library tambahan yang belum tersedia, install terlebih dahulu menggunakan pip install sesuai kebutuhan notebook.

Link Google Colab untuk setiap notebook dapat ditambahkan pada bagian daftar pertemuan apabila sudah tersedia.

Perjalanan belajar Data Science dari Pertemuan 1 hingga 13 dimulai dari dasar Python, pengolahan dataset, data cleaning, statistik deskriptif, hingga visualisasi data.
